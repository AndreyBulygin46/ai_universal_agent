# Подробный план разработки универсального ИИ-агента

## 📋 Общая структура проекта

```
ai_universal_agent/
├── app.py                    # Основной Flask-сервер
├── config.py                 # Конфигурация (API ключи, настройки)
├── database/
│   ├── models.py             # SQLAlchemy модели (чаты, инструкции, сессии)
│   └── database_manager.py   # Управление сессиями БД
├── agents/
│   ├── base_agent.py         # Базовый класс агента
│   ├── thinking_agent.py     # Логика "думания" агента
│   └── instruction_manager.py # Управление инструкциями
├── ai_engine/
│   ├── mistral_client.py     # Клиент Mistral AI
│   ├── openrouter_client.py  # Клиент OpenRouter
│   └── provider_registry.py  # Регистрация провайдеров
├── data_processor/
│   └── processor.py          # Обработка данных от пользователя
├── interfaces/
│   └── web_ui.py             # Flask-маршруты и шаблоны
├── utils/
│   ├── logger.py             # Логирование
│   └── helpers.py            # Вспомогательные функции
└── tests/                    # Тесты
```
